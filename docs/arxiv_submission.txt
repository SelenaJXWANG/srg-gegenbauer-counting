ENGLISH

The delivered srg-gegenbauer-counting.zip is the GitHub/reproduction handoff.
It has not been submitted to or validated by arXiv. Prepare a separate source
submission, rather than treating the complete handoff ZIP as upload-ready.

The two standalone source documents to preserve are:
  paper/Nonexistence_of_Strongly_Regular_Graphs_via_Gegenbauer_Positivity_and_SRG_Counting_2026-10-14.tex
  paper/Nonexistence_of_Strongly_Regular_Graphs_via_Gegenbauer_Positivity_and_SRG_Counting_Supplement_405_2026-10-14.tex

For a combined article and supplement, select both as top-level TeX sources,
in main-then-supplement order, and inspect arXiv's compiled preview. Keep TeX
outside anc/. Remove generated article PDFs, .aux, .log and other build
outputs from the TeX submission area. Retain any genuinely required source
assets; these two current documents use inline bibliographies. Metadata to
paste into the submission form is provided in arxiv_metadata.txt. [1,3]

The complete source lists used by the proofs must be publicly obtainable:
publish a fixed repository release or persistent archived version (for example
one with a DOI), and cite its actual identifier; or distribute a properly
prepared ancillary package. A private repository or this local ZIP alone does
not give readers public access. The fixed certificate manifest identifies the
data, but its hash does not itself distribute them.

arXiv ancillary data/code belong under a root anc/ directory, which must not
contain TeX files. Do not put this entire handoff ZIP into anc/ unchanged:
our actual-table verifiers require both TeX files. An ancillary variant needs
separate repackaging and a tested way to locate those TeX sources outside
anc/. Do not assume internal links into anc/ will remain valid. [2]

Before submission, confirm public access to the cited exact source lists,
check the proposed upload layout and main/supplement compilation order,
and rerun the exact verifier from a fresh download of the distributed data.
The current command is python3 -S code/verify.py. No remote publication or
arXiv upload has been performed in this handoff.
