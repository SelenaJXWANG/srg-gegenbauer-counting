The GitHub main PDF is an exact copy of the official arXiv v1 PDF.
The main TeX, 405 supplement TeX and all 64 fixed certificate/verification
inputs match the deposited archive. See paper/README.md and
extras/arxiv_version.json for the comparison scope and hashes.

The main article is arXiv v1's only top-level compiled document. The
supplement and repository were deposited under anc/. The 405 supplement
PDF in paper/ is a separate companion document, not extra pages of the
main arXiv PDF.

paper/arxiv-sources.zip is a compact editing/compilation bundle containing
the two standalone TeX documents and 00README.json. Both TeX files match
arXiv, but this bundle is not the full deposited source archive. For the
original archive and its exact compilation configuration, use the pinned
source link above.

For future revisions, edit the TeX, compile and inspect both documents,
run python3 -S code/verify.py, and keep the fixed certificate snapshot
identified separately. Updating this repository does not submit an arXiv
replacement. After a replacement is announced, compare that exact version
before updating the GitHub PDF, version record and citation metadata.
