# Collaborator upload / 共同作者上傳

1. Extract the ZIP and check the main PDF and the three language versions of the README.
2. Create a new **private** GitHub repository, for example `srg-gegenbauer-counting`.
3. Upload the extracted folder's contents at the repository root, including the hidden `.gitignore` file. Do not upload the enclosing ZIP or generated local `results/runs/` directory.
4. Run `python3 -S code/verify.py` from the uploaded checkout. The retained release result is in `results/release_checks/summary.json`.

No account credentials or access tokens are included in this handoff.

## 简体中文

1. 解压 ZIP，检查正文 PDF 与三个语言版本的 README。
2. 创建新的 **private（私有）** GitHub 项目，例如 `srg-gegenbauer-counting`。

本交接资料不包含账户凭据或访问令牌。
