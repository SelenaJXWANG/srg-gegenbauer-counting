# Release checks / 本版核驗

`summary.json` records a full five-stage exact replay from a clean archive extraction. Detailed finite-arithmetic reports are under `details/`. `discovery_input_check.json` records syntax and model-input checks only; it does not claim a new optimization run. `input_preservation.json` records byte equality with the previously verified mathematical sources. Final document/layout checks are recorded separately if supplied.

`summary.json` 記錄乾淨解壓後的五階段精確重播，詳細算術結果位於 `details/`。數值探索檢查只核對語法及模型輸入，不代表重新執行最佳化。來源保留報告記錄數學資料與先前來源逐位元一致。
